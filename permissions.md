# Sound asset permissions

## License basis

The assets listed below are from Kenney's official audio packs. Each pack page identifies its license as Creative Commons Zero (CC0), and each downloaded archive includes a `License.txt` that also says Creative Commons Zero. CC0 allows use, modification, and redistribution, including commercially, without attribution requirements. This is a practical summary, not legal advice. Kenney asset pages: [Interface Sounds](https://kenney.nl/assets/interface-sounds), [Impact Sounds](https://kenney.nl/assets/impact-sounds), [RPG Audio](https://kenney.nl/assets/rpg-audio), and [Music Jingles](https://kenney.nl/assets/music-jingles). License text: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

The original source files were copied unchanged; only filenames were changed. All additions retain their source `.ogg` encoding. The suggestions below describe how the files are used in this library.
